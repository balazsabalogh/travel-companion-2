# Travel Companion · Antalya 0.8.0 beta1

**Professional UX Preview** az RC8 Final Candidate stabil alapjára építve.

## Mi változott?
- 4 lépéses interaktív onboarding új felhasználóknak; Beállításokból bármikor újraindítható.
- Útitervben **✨ Optimalizálás**: csak javaslatot készít, és kizárólag jóváhagyás után módosítja a sorrendet.
- **Google Maps** napi útvonal-export; tömegközlekedésnél nem talál ki hamis multi-stop útvonalat, hanem a következő cél valódi Google Transit nézetét nyitja.
- Beállításokban **Frissítés ellenőrzése**; a `version.json` hálózat-első ellenőrzést kapott.
- Új, additív design tokenek és egységes professzionális komponensek az új funkciókhoz.

## Mi maradt változatlan?
A már stabil RC8 térképes navigáció, Lépések nézet, Apple/Google Transit átadás, alsó dock, Sonar tap/long-press logika, sheet-geometria, napnézetek, POI főműveletek, swipe-ok és drag & drop.

## Telepítés
A ZIP teljes tartalmát töltsd fel a GitHub Pages repository gyökerébe, felülírva az előző build fájljait.

**Fontos:** az RC8 ZIP-et tartsd meg visszaállási pontként, amíg ezt a 0.8.0 beta buildet legalább egy iPhone-on és egy Android/Chrome készüléken ki nem próbáltad.
